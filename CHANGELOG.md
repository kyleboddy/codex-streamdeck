## 1.0.0 - 2026-07-15

### Added

- Direct Stream Deck + controls for New Task, Review Changes, Approve, Decline, Stop, and Fork.
- Two JSON-configurable blank key slots.
- Brainpower encoder with Light, Medium, High, Extra High, Max, and Ultra levels.
- Dynamic Model encoder backed by the live Codex `model/list` catalog.
- Touch-strip feedback and unique production artwork for all marketplace actions.
- Shared Codex app-server transport with desktop JSONL-to-WebSocket bridging.
- Windowless .NET launcher and Node single-executable transport.
- Connection-bound approval handling through a local named pipe.
- Stream Deck + profile installer, diagnostics, recovery, and packaged plugin scripts.
- Automated controller, feedback, layout, and artwork tests.
