# Generated artwork sources

These 13 square source images were generated specifically for Codex Command Center with high-effort OpenAI image generation on 2026-07-15. They are the editable high-resolution masters, not placeholders or borrowed product artwork.

`scripts/generate-assets.ps1` deterministically resizes them into:

- 72/144-pixel Stream Deck key and encoder images;
- 20/40-pixel marketplace action-list images;
- 28/56-pixel category images;
- 256/512-pixel plugin identity images.

The names map directly to the manifest actions. `category.png` is also the plugin identity master.
